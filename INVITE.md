# Invite only

Visibility: **private**. There is no public clone URL that works for strangers.

## How to invite a reviewer

1. Open https://github.com/superrep2/qsrc-control-plane/settings/access
2. Add people → GitHub username
3. Role: **Read** for review, **Write** only if they will push patches
4. They accept the email/GitHub invite

Do not make the repository public. Do not enable GitHub Pages.

No collaborators were added when this tree was first uploaded.
The owner must name each invitee.
